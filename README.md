# LabKeeper

학교 과학실 통합 관리 시스템

## 목적

학교 과학실의 물품과 화학 시약을 한곳에서 관리하고 기록한다.

## 방향

1. **과학실 물품 대장 관리 및 기록**
   - 과학실 물품(기자재, 소모품 등) 대장 작성과 관리
   - 입고, 사용, 폐기 등 변경 기록
2. **화학 시약 관리 시스템**
   - 학교 보유 화학 시약 목록과 보관 현황 관리
   - 사용 및 폐기 기록

## 사용자

| 구분 | 인원 | 역할 |
| --- | --- | --- |
| 운영 관리 교사 | 1명 | 전체 관리, 사용자 관리, 설정 |
| 추가 사용자 | 여러 명 (다른 과학 교사) | 물품·시약 조회, 사용 기록 등 (세부 권한은 추후 정의) |

## 기술 구성

| 영역 | 기술 |
| --- | --- |
| 화면(프론트엔드) | Vite + React |
| 서버 로직 | Google Apps Script (GAS) |
| 데이터 저장소 | Google Spreadsheet |
| 배포 | 화면(React)은 Vercel 등에 따로 호스팅, GAS는 데이터 처리(API)만 담당 |

## 개발 순서

1. PC 브라우저용 개발
2. PC용 완료 후 모바일 화면 대응 추가 개발
