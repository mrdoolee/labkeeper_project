# LabKeeper

학교 과학실 통합 관리 시스템

## 목적

학교 과학실의 물품과 화학 시약을 한곳에서 관리하고 기록한다.

## 방향

물품·시약 목록(대장)에 그치지 않고, **어디에 무엇이 있는지**, **어떻게 다루는지**, **어떤 장부가 필요한지**까지 한곳에서 관리한다.

1. **과학실 물품 대장 관리 및 기록**
   - 과학실 물품(기자재, 소모품 등) 대장 작성과 관리
   - 입고, 사용, 폐기 등 변경 기록
2. **화학 시약 관리 시스템**
   - 학교 보유 화학 시약 목록과 보관 현황 관리
   - 사용 및 폐기 기록
3. **보관 위치 관리 및 열람**
   - 초기 세팅에서 교구장·시약장의 형태를 표 또는 그림으로 구성
   - 구성한 교구장·시약장을 구역으로 나누어 할당
   - 구역마다 보관 중인 장비·시약을 관리하고, 위치 화면에서 바로 열람
4. **장부 작성 및 출력**
   - 운영에 필요한 장부를 앱에서 작성하고 출력
5. **관리 정보 통합**
   - 기구: 사용연한 등 기본 정보, 사용법
   - 시약: 관리·보관 가이드라인
   - MSDS(물질안전보건자료), GHS(유해성 분류·그림문자) 정보

## 사용자

| 구분 | 인원 | 역할 |
| --- | --- | --- |
| 운영 관리 교사 | 1명 | 전체 관리, 사용자 관리, 설정 |
| 추가 사용자 | 여러 명 (다른 과학 교사) | 물품·시약 조회, 사용 기록 등 (세부 권한은 추후 정의) |

## 기술 구성

| 영역 | 기술 |
| --- | --- |
| 화면(프론트엔드) | Vite + React |
| 서버 로직 | Google Apps Script (GAS) |
| 데이터 저장소 | Google Spreadsheet |
| 배포 | 화면(React)은 Vercel 등에 따로 호스팅, GAS는 데이터 처리(API)만 담당 |

## 개발 순서

1. PC 브라우저용 개발
2. PC용 완료 후 모바일 화면 대응 추가 개발
