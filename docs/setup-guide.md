# LabKeeper 설치 안내 (GAS + Vercel)

LabKeeper는 두 부분으로 나뉩니다.

- **서버(데이터 저장)**: 구글 스프레드시트에 붙은 Apps Script(GAS) 웹 앱. 선생님 구글 계정으로 한 번 배포합니다.
- **화면**: Vercel에 올린 웹 페이지. 위 GAS 주소로 데이터를 주고받습니다.

처음 한 번만 하면 되고, 30분 정도 걸립니다.

## 1. 스프레드시트와 Apps Script 만들기

1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 누르고, 이름을 **LabKeeper DB**로 바꿉니다.
   - 이 파일이 모든 기록이 저장되는 곳입니다. 다른 사람과 공유하지 마세요. 앱 사용자는 이 파일에 접근할 필요가 없습니다.
2. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 **파일** 목록의 `Code.gs` 내용을 모두 지웁니다.
4. 저장소의 `gas/src` 폴더에 있는 파일마다 같은 이름의 스크립트 파일을 만들고 내용을 붙여 넣습니다.
   - 파일 옆 **+ → 스크립트**로 새 파일을 만들고, 이름은 확장자 없이 적습니다(예: `Auth`). 화면에는 `Auth.gs`로 보입니다.
   - 만들 파일: `Auth`, `Code`, `Db`, `Records`, `Schema`, `Settings`, `Users`
   - 파일 순서는 상관없습니다.
5. 디스크 모양 **저장** 버튼을 누릅니다.
6. (권장) 왼쪽 톱니바퀴 **프로젝트 설정**에서 **시간대**를 `(GMT+09:00) 서울`로 바꿉니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. **유형 선택**(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `LabKeeper`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
     - 앱이 자체 로그인(교사별 아이디·비밀번호)으로 사용자를 확인하므로, 구글 로그인 없이 접속할 수 있게 열어 둡니다. 스프레드시트 자체는 여전히 선생님만 볼 수 있습니다.
4. **배포**를 누릅니다.
5. 권한 승인 창이 뜨면 **액세스 승인 → 본인 계정 선택**을 누릅니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → LabKeeper(으)로 이동(안전하지 않음)**을 누른 뒤 **허용**합니다. 선생님이 직접 만든 스크립트라서 나오는 안내입니다.
6. **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둡니다.
7. 브라우저 새 탭에 이 주소를 붙여 넣었을 때 `{"ok":true,"data":{"name":"LabKeeper"}}`가 보이면 성공입니다.

### 코드를 고친 뒤 다시 배포할 때

**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 하면 웹 앱 URL이 바뀌지 않습니다. "새 배포"를 다시 누르면 URL이 새로 생기므로 주의하세요.

## 3. 화면을 Vercel에 올리기

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인합니다.
2. **Add New → Project**에서 `labkeeper_project` 저장소를 고릅니다.
3. 다음처럼 설정합니다.
   - **Root Directory**: `web`
   - Framework Preset: Vite (자동으로 잡힙니다)
   - **Environment Variables**: 이름 `VITE_GAS_URL`, 값은 2단계에서 복사한 웹 앱 URL
4. **Deploy**를 누르고, 끝나면 나오는 주소(예: `https://labkeeper-xxx.vercel.app`)를 엽니다.

GAS 주소를 바꿨다면 Vercel의 **Settings → Environment Variables**에서 `VITE_GAS_URL`을 고친 뒤 **Deployments → Redeploy**를 누릅니다.

## 4. 처음 접속

1. Vercel 주소로 들어가면 **운영 교사 계정 만들기** 화면이 나옵니다. 아이디·이름·비밀번호(8자 이상)를 정합니다.
2. **설정**에서 학교 이름, 학교급, 장부 양식 지역(기본 충북), 서명자 이름을 입력합니다.
3. **계정 관리**에서 다른 선생님 계정을 만듭니다. 화면에 한 번만 보이는 임시 비밀번호를 전해 주세요. 처음 로그인하면 본인 비밀번호로 바꾸게 됩니다.
4. **교실·보관장**에서 교실과 보관장을 등록합니다. 같은 모양의 보관장은 **복제**로 빠르게 만들 수 있습니다.

## 자주 묻는 것

- **로그인이 몇 초 걸려요.** 비밀번호를 안전하게 확인하느라 계산을 여러 번 합니다. 5초 넘게 걸리면 알려 주세요.
- **비밀번호를 잊었어요.** 운영 교사가 **계정 관리 → 비밀번호 초기화**로 임시 비밀번호를 새로 줍니다.
- **스프레드시트를 직접 고쳐도 되나요?** 열 순서를 바꾸거나 메모 열을 추가하는 것은 괜찮습니다. 다만 `id`, `deleted` 같은 열의 값을 고치면 기록이 꼬일 수 있으니 앱에서 고치는 것을 권합니다.
- **기록을 지웠어요.** 삭제는 표시만 남기고 실제로 지우지 않습니다. 변경 이력에서 누가 언제 지웠는지 확인할 수 있습니다.

## 개발자용: 로컬에서 실행

```bash
cd gas && npm install && npm run dev      # 가짜 구글 서비스로 GAS 코드를 띄움 (http://127.0.0.1:8787, 데이터는 메모리)
cd web && npm install && cp .env.example .env.local && npm run dev
```
