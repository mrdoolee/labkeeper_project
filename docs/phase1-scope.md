# 1차 개발 범위

1차는 **시약 관리**와 **충북 서식 1·3·4·5 운영**까지 만든다. 과학 물품(교구) 등록은 2차로 넘긴다.

## 1. 기능

1. **로그인과 계정 관리**
   - 교사별 아이디·비밀번호. 첫 실행 때 운영 교사 계정 생성
   - 운영 교사가 일반 교사 계정 생성, 임시 비밀번호 발급·초기화. 첫 로그인 때 비밀번호 변경
2. **기본 설정**
   - 학교명, 과학실(여러 개), 점검자·확인자·결재자 이름
   - 보관장(시약장 등)과 구역(칸) 구성: 행×열 표 형태
3. **시약 등록**
   - 약품명, 화학식, CAS No., 농도, 용량·단위, 제조사·구입처, 구입일, 개봉일, 유효기간, 보관 구역
   - 유독물질·사고대비물질 자동 판정 (CAS No. + 농도, 경기 매뉴얼 부록 9 기준농도표)
4. **시약 입고·사용·폐기 기록** → 서식3에 자동 반영
5. **폐수·폐시약 발생·처리 기록** → 서식4에 자동 반영
6. **월간 점검표 입력** → 서식1, 서식5
7. **서식 출력** (A4 인쇄, 서명란 포함)

## 2. 운영할 서식 (충북 2026 과학교육 기본 계획 부록 기준)

| 서식 | 이름 | 단위 | 입력 방식 | 출력 |
| --- | --- | --- | --- | --- |
| 서식1 | 과학실 안전 관리 점검표 | 과학실별, 월 1회(매월 4일) | 항목별 ○(양호)·△(보통)·×(미흡), 특이사항 | A형(점검일 1회분) 또는 B형(1~12월 누계) 선택 |
| 서식3 | 화학물질 관리대장 | 약품별 | 입고·출고 기록에서 자동 생성 | 약품별 대장 |
| 서식4 | 실험·실습 폐수·폐기물 관리(처리)대장 | 성상별(산, 염기, 유기물, 무기물, 폐시약) | 발생·처리 기록에서 자동 생성 | 성상별 대장 |
| 서식5 | 과학실험실 내 폐수·폐시약 점검표 | 과학실별, 월 1회(매월 4일) | 항목별 ○·△·×, 특이사항 | A형 또는 B형 선택 |

서식별 항목

- **서식1**: A형 27개 항목, B형 영역별 항목(안전관리 계획, 안전교육, 실험안전 관련자료 게시, 안전관리, 유해화학물질 및 실험기자재 관리, 기타). 점검자(과학부장), 교감, 확인자(교장) 서명란
- **서식3**: 상단 약품명, CAS No., 금지·허가·제한·유독·사고대비물질 해당 여부(○). 기록 칸 연월일, 수불구분(입고/출고), 수불량, 보유량, 잔량, 용도(실험/구입처), 확인, 비고. 유해화학물질은 약품명을 눈에 띄게 표시. 5년 보존
- **서식4**: 상단 성상별 종류, 단위(L, g). 기록 칸 연월일, 이월량, 발생량, 처리량, 잔량, 처리현황, 처리방법(교육청 위탁/학교 자체처리), 수거(처리) 업체, 확인. 3년 보존
- **서식5**: 18개 항목(안전한 처리계획 수립 및 관리, 안전한 보관 및 처리). 100㎡ 이상 고등학교만 해당하는 항목(4, 5번)과 독자 처리 학교만 해당하는 항목(11번)은 "해당 없음" 처리 가능. 점검자(과학부장), 확인자(교감) 서명란

## 3. 1차에서 하지 않는 것

- 과학 물품(교구) 등록 → 2차
- 서울·경기 양식 선택 (1차는 충북 양식만)
- 보관 위치 추천과 정돈, 공존 불가 경고
- MSDS 파일 보관, data.go.kr API 참고자료, 경고표지 출력
- 서식2(유해화학물질 표시), 서식6(사안 보고), 유해화학물질 취급시설 주간 점검대장
- 모바일 화면
