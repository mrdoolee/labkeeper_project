# 여러 학교 공용 구조(스프레드시트 연결) + 화면 디자인 B 설계

날짜: 2026-10-23
상태: 초안 (사용자 승인 전)

## 1. 왜 바꾸는가

LabKeeper는 지금 Vercel 빌드에 GAS 주소(`VITE_GAS_URL`)를 넣어 한 학교만 쓰는 구조다.
사용자는 arbot(`mrdoolee/arbot-project`, https://arbot-trdoolee.vercel.app)과 같은 구조를 원한다.

- Vercel 화면은 **하나만 배포**하고 여러 학교가 같은 주소를 쓴다.
- 각 학교는 **자기 스프레드시트**에 GAS를 배포하고, 그 시트가 그 학교의 DB가 된다. 데이터는 각 학교 시트에만 있다.
- 웹앱을 처음 열면 **스프레드시트 연결이 먼저**다. 연결된 뒤에 계정·로그인·업무 화면을 쓴다.

함께, 화면 전체를 시안 B("레퍼런스 구조 + 차분한 색")로 바꾼다.
시안: https://claude.ai/artifact/FTVWLVHu7F2uGEKGRi6oHK (B = `Calm.dc.html`)

## 2. 목표 / 비목표 / 반목표

**목표**
1. 웹앱 첫 화면에서 GAS 주소를 넣고 연결 테스트 후 저장한다. 저장된 주소는 그 브라우저에 남는다.
2. 운영 교사가 "우리 학교 접속 링크"(`…/?gas=<GAS 주소>`)를 복사해 다른 선생님께 전한다. 선생님은 링크를 열고 로그인만 하면 된다.
3. 첫 운영 교사 계정은 **스프레드시트 메뉴에서만** 만든다(검토 항목 M11 해결).
4. 화면이 요구하는 GAS 버전보다 학교 시트의 GAS가 낮으면 다시 배포하라고 안내한다.
5. 운영 중인 시트를 통째로 복사한 사본을 감지해서 막는다.
6. 화면 전체를 시안 B로 바꾼다: 아이콘이 있는 어두운 왼쪽 메뉴, 메뉴 접기, 메뉴 아래 사용자 칸, 파란 강조색, 교실 목록 카드.
7. GAS에 연결하지 못하면 안내 문구를 보여 준다(검토 항목 M9 해결).

**비목표 (이번에 하지 않음)**
- Tailwind·shadcn 도입 (사용자가 ① "지금 방식 유지 + 아이콘만 추가"를 골랐다)
- 휴대폰 화면, 햄버거 메뉴, 다크 모드 (PC 먼저 원칙)
- 학교 코드·중앙 목록 서버 (사용자가 A "arbot 방식"을 골랐다)
- QR 코드 (교사끼리 PC로 링크를 주고받으므로 복사 버튼으로 충분)
- 학교 시트의 GAS 자동 업데이트 (버전 안내까지만)

**반목표 (이렇게 되면 실패)**
- 조작된 링크 때문에 선생님 비밀번호가 다른 서버로 간다.
- 한 학교에서 다른 학교의 데이터가 보인다.
- 지금 쓰는 시트의 데이터가 사라진다.
- 기록 원칙(작성자·수정자·삭제자·변경 이력)이 빠진다.

## 3. 접근 방법 (사용자가 고른 것)

| | 선택지 | 결정 |
|---|---|---|
| 연결 정보 | **A. 브라우저에 GAS 주소 저장 + `?gas=` 접속 링크** / B. 짧은 학교 코드 + 중앙 목록 | **A** — 서버가 더 필요 없고 arbot에서 검증됨. B는 중앙 저장소가 필요하고 "데이터는 각 학교 시트에만" 원칙에서 벗어남 |
| GAS 코드 배포 | **① 코드가 든 원본 시트 "사본 만들기"** / ② Apps Script 라이브러리 | **①** — arbot과 같음. ②도 학교마다 버전을 올려야 해서 이점이 작고 구조만 복잡해짐 |
| 화면 스타일 | **① 지금 CSS 유지 + lucide-react 아이콘** / ② Tailwind + shadcn | **①** — 기존 화면·테스트를 살리고 의존성은 아이콘 하나만 추가 |

작업 순서: **1부 연결 구조 → 2부 디자인**. 두 부분은 서로 독립이다.

## 4. 1부 — 스프레드시트 연결 구조

### 4.1 학교가 하는 일 (새 흐름)

1. 안내서의 "원본 사본 만들기" 링크로 **LabKeeper 원본 시트**를 내 드라이브에 복사한다. 코드가 이미 들어 있다.
2. 시트 메뉴 **확장 프로그램 → Apps Script → 배포 → 새 배포 → 웹 앱**(실행: 나, 액세스: 모든 사용자)으로 배포하고 URL을 복사한다.
3. 시트 상단 **LabKeeper → 운영 교사 계정 만들기**에서 아이디·이름·비밀번호를 정한다.
4. 공용 웹 주소를 열고 **스프레드시트 연결** 화면에 URL을 붙여 넣는다 → 연결 테스트 → 저장 → 로그인.
5. **계정 관리**에서 선생님 계정을 만들고, 임시 비밀번호와 **우리 학교 접속 링크**를 전한다.

### 4.2 GAS 쪽 변경

- **`system.info` 액션 추가** (인증 없음, 읽기 전용). 반환: `{ name: 'LabKeeper', apiVersion, needsSetup, copied, schoolName }`.
  - `apiVersion`: GAS 코드의 `API_VERSION` 상수. 이번 변경으로 `2`(현재 코드를 1로 본다). 화면이 새 액션을 쓰기 시작할 때마다 GAS와 화면의 숫자를 함께 올린다.
  - `needsSetup`: Users 시트에 행이 하나도 없으면 true (지금 `setup.status`와 같은 규칙).
  - `copied`: 4.4의 사본 감지 결과.
  - `schoolName`: 설정의 학교 이름(빈칸 가능). 로그인 화면에 "어느 학교에 로그인하는지" 보여 주는 용도.
- **`setup.status`는 `system.info`로 대체**하고, **`setup.createAdmin` 웹 액션은 없앤다**. 웹으로는 첫 계정을 만들 수 없다.
- **스프레드시트 메뉴** (`onOpen`, 메뉴 이름 "LabKeeper"):
  - **운영 교사 계정 만들기**: 계정이 하나도 없을 때만 동작. HtmlService 대화상자(아이디·이름·비밀번호·확인, 비밀번호 칸은 가려짐)에서 입력받아 `google.script.run`으로 만든다. 규칙은 지금 `setupCreateAdmin`과 같다(작성자는 `{id:'system', name:'첫 설정'}`).
  - **운영 교사 비밀번호 초기화**: 운영 교사 아이디를 입력하면 임시 비밀번호를 만들어 대화상자에 보여 준다(다음 로그인 때 변경 필요, 이전 로그인 모두 끊김, 변경 이력에 '비밀번호 초기화', 작성자는 `{id:'sheet-owner', name:'시트 소유자'}`). 운영 교사가 1명뿐인데 비밀번호를 잊으면 지금은 복구 방법이 없어서 필요하다.
  - **시트 구조 점검**: 표(시트)와 1행 머리글 이름이 맞는지 확인하고 빠진 것을 알려 준다. 고치지는 않는다.
  - **사용 가이드**: 간단한 안내(설치 순서, 접속 링크, 재배포 방법)를 대화상자로 보여 준다.
- **변경 이력 원칙**: 메뉴로 만든 계정과 초기화도 AuditLog에 남긴다. `directory.list`에 `{id:'sheet-owner', name:'시트 소유자'}`를 `첫 설정`처럼 넣어 이력에 이름이 보이게 한다.

### 4.3 화면 쪽 변경

- **GAS 주소 저장** (`web/src/api/connection.ts` 새로 만들기)
  - localStorage 키 `labkeeper.gasUrl`. 저장소를 못 쓰면 메모리에 둔다(지금 토큰과 같은 방식).
  - 받아들이는 주소: `https://script.google.com/macros/s/<id>/exec` 와 `https://script.google.com/a/macros/<도메인>/s/<id>/exec`(학교 Google Workspace 계정용). 개발 빌드(`import.meta.env.DEV`)에서만 `http://127.0.0.1:<포트>`·`http://localhost:<포트>`도 받는다(로컬 GAS 서버·e2e용).
  - 주소가 바뀌면 로그인 토큰을 지운다.
- **`callApi`는 저장된 주소로 요청**한다. `VITE_GAS_URL`은 코드와 Vercel 설정에서 모두 없앤다.
- **앱 시작 순서**
  1. 주소창에 `?gas=`가 있으면 4.5 규칙으로 처리하고, 주소창에서 `?gas=`를 지운다(`history.replaceState`).
  2. 저장된 주소가 없으면 → **스프레드시트 연결** 화면.
  3. 있으면 `system.info` 호출.
     - 실패(네트워크) → **연결 오류** 화면: "스프레드시트에 연결할 수 없습니다" + 다시 시도 + 주소 바꾸기. (M9)
     - `copied` → 사본 경고 화면 (4.4).
     - `apiVersion`이 화면이 요구하는 값보다 낮음 → 재배포 안내 화면(가이드 링크).
     - `needsSetup` → "시트 메뉴 LabKeeper → 운영 교사 계정 만들기에서 첫 계정을 만드세요" 안내 화면 + 다시 확인 버튼.
     - 그 밖 → 지금처럼 로그인/업무 화면.
- **스프레드시트 연결 화면**: 주소 입력 → [연결 테스트](`system.info`를 그 주소로 호출, 성공하면 학교 이름·상태 표시) → [저장하고 계속]. 실패하면 흔한 원인(주소 형식, 액세스 "모든 사용자", 방금 배포했으면 잠시 후)을 보여 준다. 설치 안내 링크를 둔다.
- **로그인 화면**: 위에 "연결된 학교: ○○중학교"(학교 이름이 비어 있으면 "학교 이름 미설정")와 [다른 스프레드시트에 연결] 링크.
- **우리 학교 접속 링크**: 계정 관리 화면(운영 교사만)에 링크와 [복사] 버튼. "새 선생님께 이 링크와 임시 비밀번호를 전해 주세요" 안내.
- **스프레드시트 바로 열기**: 계정 관리 화면에 [스프레드시트 열기] 버튼. 시트 주소는 운영 교사에게만 주는 액션(`system.sheetUrl`, 관리자 인증)으로 받는다.
- **AuthContext**: `setup.status`/`setupAdmin` 대신 `system.info` 결과를 쓴다. `SetupPage`(웹에서 계정 만들기)는 4.3의 안내 화면으로 바뀐다.

### 4.4 사본 감지

- ScriptProperties에 `OWNER_SPREADSHEET_ID`를 둔다.
- `system.info`와 모든 요청 처리 전에 확인한다.
  - 값이 없으면 → 지금 시트 ID를 적는다(새로 복사한 원본, 또는 이 기능 전부터 쓰던 시트).
  - 값이 지금 시트 ID와 같으면 → 정상.
  - 값이 다르고 **Users 시트에 행이 없으면** → 원본(빈 시트)을 복사한 새 학교다. 지금 시트 ID로 바꿔 적는다.
  - 값이 다르고 **Users 시트에 행이 있으면** → 운영 중인 시트의 사본이다. `copied: true`, 다른 요청은 `SHEET_COPIED` 오류로 거절한다.
- 사본 해제: 시트 메뉴 **사본을 새 학교 시트로 시작**. 확인 대화상자 뒤 모든 표의 데이터 행을 지우고(머리글은 남김) 지금 시트 ID를 주인으로 적는다. 되돌릴 수 없다는 경고를 보여 준다.
- 로그인 세션(CacheService)은 스크립트마다 따로라서 사본으로 넘어가지 않는다.

### 4.5 `?gas=` 접속 링크 처리 (보안)

- 형식이 4.3 규칙에 맞지 않으면 무시한다.
- 저장된 주소가 없으면 → 저장하고 진행한다.
- 저장된 주소와 같으면 → 그대로 진행한다.
- **저장된 주소와 다르면** → 바로 바꾸지 않고 확인 화면을 보여 준다: "다른 학교 스프레드시트로 연결을 바꿀까요? 지금: ○○중학교 / 새 링크: △△중학교". 바꾸면 토큰을 지운다.
- 로그인 화면에 항상 학교 이름을 보여 준다. 조작된 링크로 엉뚱한 서버에 로그인하려 할 때 알아챌 수 있게 하기 위해서다.
- 한계: script.google.com에는 누구나 스크립트를 올릴 수 있으므로 형식 검사만으로 완전히 막지는 못한다. 안내서에 "접속 링크는 운영 교사에게 직접 받은 것만 쓰라"고 적는다.

### 4.6 원본 시트와 코드 배포

- **원본 시트**: 사용자가 자기 드라이브에 빈 "LabKeeper 원본" 시트를 만들고 코드를 넣어 둔다(데이터·계정 없음). "링크가 있는 모든 사용자: 뷰어"로 공유하고, 안내서에 `https://docs.google.com/spreadsheets/d/<ID>/copy` 링크를 적는다.
  - Claude는 구글 시트에 코드를 직접 넣을 수 없으므로, 이 단계는 사용자가 한다(안내서에 순서를 적는다).
- **학교용 코드 한 파일**: `gas/src`의 파일들을 하나로 이어 붙인 `gas/dist/LabKeeper.gs`를 만드는 스크립트(`npm run bundle`)를 둔다. 코드를 업데이트할 학교는 이 파일 하나만 붙여 넣고 "새 버전"으로 다시 배포하면 된다. `gas/src`가 바뀌면 묶음도 다시 만든다(테스트가 묶음이 최신인지 확인).
- **지금 쓰는 학교 시트(사용자 본인)**: 새 코드를 붙여 넣고 같은 배포를 "새 버전"으로 다시 배포 → 시트 메뉴에서 운영 교사 계정 만들기 → Vercel에서 `VITE_GAS_URL` 삭제. 기존 데이터는 그대로 남는다(표 구조는 바뀌지 않음).

### 4.7 테스트

- GAS (node:vm 가짜 서비스): `system.info`의 각 값, `setup.createAdmin` 제거, 메뉴 함수(계정 만들기·비밀번호 초기화·사본 해제)의 규칙과 이력, 사본 감지 4가지 경우, `SHEET_COPIED` 거절, 묶음 파일 최신 여부. 가짜 서비스에 ScriptProperties·`getId()`를 추가한다.
- 화면 (Vitest): 주소 형식 검사(허용·거부 예), `?gas=` 처리 3가지 경우, 시작 순서의 각 갈래 화면, 연결 테스트 성공·실패, 접속 링크 복사.
- e2e: 연결 화면에서 로컬 GAS 주소 입력 → 연결 → (첫 계정은 테스트 도우미가 메뉴 함수로 만듦) → 로그인 → 기존 시나리오.

### 5.2 화면 구조

- **왼쪽 메뉴** (`Layout.tsx`): 위 로고(플라스크 아이콘 + LabKeeper) + 접기 버튼, 가운데 메뉴(아이콘 + 이름: 홈, 교실·보관장, 설정, 계정 관리(운영 교사만)), 아래 사용자 칸(이름 첫 글자 동그라미, "○○○ 선생님", 역할, 로그아웃 아이콘 버튼).
  - **접기**: 접으면 아이콘만 보이는 좁은 메뉴(약 72px). 아이콘에 `aria-label`과 `title`로 메뉴 이름. 접힘 상태는 localStorage에 기억(실패해도 동작).
  - 아이콘: `lucide-react` (Home, LayoutGrid, SlidersHorizontal, Users, LogOut, ChevronLeft, FlaskConical, Search, Archive).
- **위쪽 줄**: 보관장 찾기(돋보기 아이콘 포함)만 둔다. 이름·로그아웃은 메뉴 아래로 옮긴다.
- **교실 목록** (`RoomsPage`): 표 → 카드 격자. 카드에 상자 아이콘, 교실 이름, "과학실" 배지, 보관장 개수, 마지막 수정자·일시. 카드를 누르면 교실 화면. 과학실 여부 바꾸기·이름 바꾸기·삭제는 카드 안의 작은 버튼으로 둔다(지금 표에 있는 기능을 그대로 유지).
- **나머지 목록** (교실 안 보관장, 계정, 삭제된 항목, 변경 이력): 표 그대로 두고 새 색·모서리만 적용한다.
- **로그인·연결·안내 화면**: 가운데 카드에 로고 타일(파란 사각형 + 플라스크)과 제목. 시안 B와 같은 색.

### 5.3 테스트

- 기존 화면 테스트는 역할·이름(버튼, 링크, "주 메뉴")으로 찾으므로 대부분 그대로 통과해야 한다. 교실 목록이 표에서 카드로 바뀌는 테스트만 고친다.
- 새 테스트: 메뉴 접기(아이콘만 보이고 이름은 aria-label로 남음, 다시 펴짐), 사용자 칸 로그아웃.
- e2e 스크린샷(`docs/screenshots/`)을 새로 찍는다.

## 7. 빌더에게 맡기는 것 (Claude가 정한 것 포함)

- 사본 감지 규칙(4.4): "주인 ID가 다르고 계정이 있으면 사본"은 Claude의 판단이다. arbot은 비밀번호만 지우지만, LabKeeper 사본에는 다른 학교 계정과 기록 전체가 따라가므로 막는 쪽을 택했다.
- 메뉴로 만든 계정과 초기화의 작성자 표기(`첫 설정`, `시트 소유자`)는 Claude의 판단이다.
- 접속 링크와 시트 열기 버튼을 **계정 관리 화면(운영 교사만)** 에 둔 것은 Claude의 판단이다. 계정을 만들어 줄 때 함께 전하기 때문이다.
- 교실 목록만 카드로 바꾸고 다른 목록은 표로 둔 것은 Claude의 판단이다(시안이 교실 목록만 보여 줬고, 표가 많은 정보를 빽빽하게 보여 주기에 낫다).
- 메뉴 접힘 너비, 아이콘 크기 같은 세부 수치.

## 8. 위험과 확인할 것

- 학교 Google Workspace(교육청 계정)에서 웹앱 액세스를 "모든 사용자"로 열 수 없게 막아 둔 경우가 있다. 그러면 공용 화면에서 연결할 수 없다. 안내서에 "개인 Gmail 계정으로 원본을 복사·배포"하라고 적는다.
- 코드가 바뀔 때마다 각 학교가 다시 배포해야 한다. 버전 안내로 알리지만, 학교가 하지 않으면 그 학교는 새 화면을 못 쓴다.
- 지금 Vercel에 넣어 둔 `VITE_GAS_URL`은 새 화면 배포 뒤 지운다(남겨 둬도 쓰이지 않음).
