# 시약 등록 때 화학물질 정보 찾아 채우기 — 설계

2026-10-29. M2(시약과 대장)에 덧붙이는 작은 기능. M4(MSDS·경고표지) 앞당김의 일부.

## 왜

시약을 한 건 등록할 때 선생님이 CAS No.·화학식을 찾아 적고, 46종 표에 없는 물질은 유독물질·사고대비물질을 직접 확인해 골라야 했다.
공공데이터포털 API로 이 네 칸(그리고 충북 양식의 금지·허가·제한물질 ○)을 채워 수고와 "판정 불가"를 줄인다.

## 정해진 것 (선생님)

- 인증키는 **학교마다 운영 교사가 data.go.kr에서 발급**받아 시트 메뉴에 넣는다(공용 키 없음).
- **새로 한 건 등록할 때만** 쓴다. 이미 등록된 시약 다시 채우기, 엑셀 일괄 등록에는 붙이지 않는다.

## 쓰는 API (2026-10-29 실제 호출로 확인)

| API | 주소 | 쓰는 곳 |
|---|---|---|
| 한국산업안전보건공단 물질안전보건자료 `getChemList001` | `https://apis.data.go.kr/B552468/msdschem1/getChemList001` (XML) | 한국어 이름으로 후보 찾기. `searchWrd`, `searchCnd=0`(국문명), `numOfRows`, `pageNo`. 응답 item: `chemNameKor`, `casNo`, `chemId` |
| 한국환경공단 화학물질 정보 `chemSbstnList` | `https://apis.data.go.kr/B552584/kecoapi/ncissbstn/chemSbstnList` (JSON) | CAS로 찾기, 분류·기준 농도·분자식. `searchGubun=2`(CAS), `searchNm`, `returnType=JSON`. item: `sbstnNmKor`, `sbstnNm2Kor`, `casNo`, `mlcfrm`, `typeList[]{sbstnClsfTypeNm, contInfo, excpInfo}` |

확인한 사실:
- 환경공단 `typeList`의 분류명: `인체등유해성물질`(또는 `인체등유해성물질 세분류`), `사고대비물질`, `금지물질`(·`세분류`), `제한물질`, `허가물질`, 그 밖에 `기존화학물질` 등(무시).
- `contInfo` 예: "인체급성유해성 : 5%, 생태유해성 : 2.5%", "염화 수소 및 이를 10% 이상 함유한 혼합물".
- 2025-08-07 개정 화학물질관리법으로 "유독물질"이 "인체등유해성물질"(인체급성·인체만성·생태유해성)로 바뀌었다. 대장 양식의 칸 이름은 "유독물질" 그대로 쓴다.
- 46종 표와 비교: "유독물질 기준 = 인체등유해성 % 중 가장 낮은 값", "사고대비 기준 = 사고대비물질 % 중 가장 낮은 값"으로 계산하면 42종이 같다. 다른 4종(벤젠 85→0.1, 염화 은 1→10, 과망가니즈산 칼륨 5→2.5(생태), 구리 해당없음→1(생태))은 표가 틀렸거나 옛 값이다.
- 분자식(`mlcfrm`)은 46종 중 16종만 있고 "H-Cl"처럼 하이픈이 섞인다.
- 한국어 이름 검색은 공단 API만 된다. "염산"으로는 염화수소가 안 나오고, 새 이름("과망가니즈산 칼륨")은 0건, 옛 이름("과망간산칼륨")만 나온다. "에탄올"은 172건. 이름에 `&lt;br/&gt;( 관용명 : … )`가 섞여 온다.
- 염화 나트륨은 환경공단에 이름이 빈 채로 있고 분류는 `기존화학물질`뿐이다.
- 오류: 키가 틀리면 게이트웨이가 `OpenAPI_ServiceResponse`(`returnReasonCode` 30 등록되지 않은 키, 22 일일 한도 초과)를 돌려준다. 결과 없음은 정상 응답에 빈 목록.
- 일반 인증키는 "Encoding"(%2F 등이 든) 형태와 "Decoding" 형태가 있다. 둘 다 받는다.

## 접근 방법

1. **GAS 서버가 API를 부르고, 판정은 화면이 한다 (채택).** 키는 학교 시트의 스크립트 속성에만 있고 화면으로 가지 않는다. data.go.kr은 브라우저 직접 호출(CORS)을 기대할 수 없다. 기존 46종 판정도 화면(`web/src/domain/hazard.ts`)에 있으니 같은 자리에 둔다.
2. 화면이 API를 직접 부른다 — 키가 브라우저에 노출되고 CORS로 막힐 수 있어 제외.
3. GAS가 판정까지 해서 결과만 준다 — 농도를 바꿀 때마다 서버를 다시 불러야 해서 제외.

## 판정 규칙 (화면, `web/src/domain/chemLookup.ts`)

- 기준 농도 = `contInfo`에 있는 `숫자%` 가운데 가장 작은 값. 해당 분류가 있는데 %가 없으면 0(농도와 상관없이 해당).
- 유독물질: `인체등유해성물질…` 또는 `유독물질…` 분류의 기준. 사고대비물질: `사고대비물질…`. 금지·허가·제한물질: `금지물질…`·`허가물질…`·`제한물질…`.
- 농도 ≥ 기준이면 해당. 농도를 비우면 100%(지금 규칙과 같음). 분류가 없으면 해당 없음.
- **API 우선 (제 결정, 선생님 미확인)**: 찾은 정보가 있으면 46종 표 대신 API로 판정한다. 화학물질안전원의 현재 고시라서. 환경공단에 그 CAS가 없으면 지금처럼 46종 표로 판정한다.
- 금지·허가·제한물질 ○도 함께 채운다. 독극물(서울 양식)은 API에 없어 그대로 둔다.
- 찾은 뒤 농도를 바꾸면 API 기준으로 다시 판정한다(금지·허가·제한 포함). CAS를 손으로 바꾸면 찾은 정보는 버리고 46종 표로 돌아간다. "직접 고른 판정"은 지금처럼 그대로 둔다.
- `excpInfo`(예외)는 판정에 쓰지 않고 근거로만 보여 준다(예: 구리 "입자 1 mm 이상 제외").

## 화면

- 새 시약 등록 화면의 약품명 칸 옆 **"찾기"** 버튼. 약품명 칸이 비어 있으면 CAS No. 칸으로 찾는다. 글자가 CAS 모양이면 CAS로, 아니면 이름으로 찾는다.
- 후보 목록(이름 · CAS)에서 하나를 누르면 정보를 받아 채운다: CAS No.(항상), 화학식(API에 있을 때), 약품명(비어 있을 때만), 판정·금지·허가·제한.
- 판정 칸 제목이 "(화학물질안전원 고시)"로 바뀌고 아래에 근거 줄(분류: 내용 [예외])을 보여 준다.
- 키가 없으면 서버 안내("운영 교사가 시트 메뉴 LabKeeper → 공공데이터 인증키 입력")를 그대로 보여 준다. 찾지 못하면 "찾은 물질이 없습니다. 다른 이름(예: 옛 이름)이나 CAS No.로 찾아 보세요."
- 고른 물질이 환경공단 정보에 없으면 "환경공단 정보에 없는 물질이라 46종 표로 판정합니다."를 보여 준다.
- 시약 상세(수정) 화면과 엑셀 등록에는 버튼이 없다.

## 서버 (GAS, 새 파일 `gas/src/Chem.js`)

- 액션 `chem.search {query}` → `{ items: [{ name, casNo }] }` (로그인 필요, 쓰기 없음)
  - CAS 모양(`isValidCas`)이면 환경공단 CAS 검색. 이름은 `sbstnNmKor`, 없으면 `sbstnNm2Kor`의 첫 이름, 그것도 없으면 CAS.
  - 아니면 공단 이름 검색 20건. 0건이고 공백이 있으면 공백을 빼고 한 번 더.
  - 이름 정리(HTML 엔티티 풀기, `<br/>`는 공백), CAS 없는 줄 빼기, 같은 (이름, CAS) 하나로, 공백 뺀 이름이 검색어와 같은 줄을 맨 앞에.
- 액션 `chem.info {casNo}` → `{ found: false }` 또는 `{ found: true, casNo, name, formula, classes: [{ type, content, exception }] }`
  - 환경공단 CAS 검색. 여러 item의 `typeList`를 합치고 (type, content) 중복 제거. `기존화학물질`·`등록대상기존화학물질`은 뺀다.
  - 화학식 = 처음 나오는 비지 않은 `mlcfrm`에서 하이픈·공백 제거.
- 키: 스크립트 속성 `DATA_GO_KR_KEY`. `%xx`가 들어 있으면 그대로, 아니면 `encodeURIComponent`.
- 오류 코드: `NO_API_KEY`(키 없음), `LOOKUP_FAILED`(HTTP 오류·게이트웨이 오류·형식 오류). 메시지는 한국어로 원인별(키 등록 안 됨, 일일 한도 초과, 그 밖). 잘못된 CAS는 `INVALID`.
- 시트 메뉴 **"공공데이터 인증키 입력"**: 지금 상태(있음·없음)를 보여 주고 키를 받는다. 빈칸으로 확인하면 키를 지운다. 처리 함수 `sheetSetDataKey(key)`.
- "배포용 원본으로 초기화"와 "사본을 새 학교 시트로 시작"은 키도 지운다(다른 학교 키가 따라가지 않게). "이 사본을 계속 쓰기"는 같은 학교라 남긴다.
- `API_VERSION` 5, 웹 `REQUIRED_API_VERSION` 5.

## 목표가 아닌 것

- 엑셀 일괄 등록 자동 채우기, 이미 등록된 시약 다시 채우기, 수정 화면의 찾기.
- 46종 표 고치기(표는 키가 없을 때의 대체 판정으로 그대로 둔다).
- 결과 캐시(하루 한도 2,000건이면 한 건 등록에는 충분).
- GHS(경고표지)·MSDS 본문 — M4.

## 만들 사람에게 맡긴 것

- 후보 목록의 모양(버튼 목록), 불러오는 중 표시.
- 근거 줄의 문구 세부.
