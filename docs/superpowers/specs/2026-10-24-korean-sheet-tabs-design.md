# 시트 탭 한국어화와 분야별 이력 설계

날짜: 2026-10-24 · 상태: 사용자 승인("진행해보자")

## 왜

학교 시트를 직접 열어 봐도 읽기 쉬워야 한다. 지금은 탭 이름·머리글이 영어이고, 작성자 칸에 긴 ID가 있고, 모든 변경 이력이 AuditLog 탭 하나에 JSON으로 쌓인다. 시약·교구가 생기면 더 읽기 어렵다.

## 결정 (사용자와 합의)

- **기록 탭**: 한국어 이름. 지금 만드는 것 — 환경설정, 계정, 교실, 보관장, 보관장 구역. 나중 — 시약, 시약 수불(M2), 폐수·폐시약, 안전점검, 폐수점검(M3), MSDS 참고자료(M4), 교구, 교구 기준(2차).
- **이력 탭**: 분야별. 지금 — 환경설정 이력(설정·학교 정보·시트 메뉴 작업), 계정 이력(계정 변경·비밀번호), 접속 기록(로그인), 교실 이력(교실·보관장·구역). 나중 — 시약 이력, 폐수·점검 이력, 교구 이력.
- **이력 열**: 왼쪽에 사람이 읽는 열(일시, 사람, 표, 대상, 동작, 바뀐 내용), 오른쪽에 앱이 쓰는 원자료(회색 머리글).
- **기록 탭 열**: 한국어 머리글, 작성자·수정자·삭제자 이름 칸, 내부 ID 칸은 오른쪽.
- **탭 색**: 기록 파랑, 이력 회색. 기록 탭은 이력 탭보다 앞에 만든다. 1행 고정.
- **지금 쓰는 개발용 시트**: 새 코드가 처음 실행될 때 옛 영어 탭을 새 이름·머리글로 바꾸고 이름 칸을 채우며, AuditLog의 기록을 분야별 이력 탭으로 옮긴 뒤 AuditLog 탭을 지운다.

## 구현 방식 (Claude의 판단)

- 코드 안의 표·열 이름(Users, roomId …)은 그대로 두고, `Schema.js`에 시트 이름·열 머리글(한국어)·열 순서를 둔다. `openTable`이 머리글(한국어)을 내부 열 이름으로 바꿔 읽는다. 사용자가 더한 열(알 수 없는 머리글)은 건드리지 않는다.
- 시각은 한국 시간 ISO 형식(`2026-10-24T14:20:00+09:00`)으로 저장한다(시트에서 바로 읽힘, 웹도 그대로 해석).
- 이름 칸(작성자·수정자·삭제자)은 기록 당시의 이름이다.
- 웹 API(`audit.list` 결과 형식)는 바꾸지 않는다. 계정 표의 이력은 계정 이력과 접속 기록을 합쳐 시간순으로 보여 준다.
- 환경설정 탭에는 사람이 읽는 "항목" 칸(학교 이름 등)을 더한다.
- 1행 고정 때문에 행 삭제가 막히지 않도록, 데이터 비우기는 필요하면 빈 행을 하나 더한 뒤 지운다.

## 하지 않는 것

- 보관장 탭에 교실 이름 칸(교실 이름이 바뀌면 함께 고쳐야 함), 종류·분류 id의 한국어화(검토 M5) — 나중에.
- API 버전 변경(웹이 쓰는 형식은 그대로).
