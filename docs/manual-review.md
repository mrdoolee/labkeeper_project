# 과학실 운영 매뉴얼 검토 결과

LabKeeper에 무엇을 구현해야 하는지 정리하기 위해 운영 매뉴얼 5종을 검토한 결과다.
기능 범위를 정할 때 이 문서를 기준으로 삼는다.

## 1. 검토한 자료

| 자료 | 성격 | 앱에 쓰이는 부분 |
| --- | --- | --- |
| 2026 충북 과학교육 기본 계획 | 도 교육청 연간 계획 | 시약 보관장별 분류 예시, 폐수 분류, 서식 1~6 |
| 2025 과학실 안전관리 및 안전매뉴얼 (서울) | 안전관리 매뉴얼 | 시약 보관 요령, 공존 불가 물질표, MSDS 운영, 서식 1~8 |
| 2025 과학실 안전관리 계획 (경기) | 안전관리 계획 | 법정 장부·게시물 목록과 보존기한, 유해화학물질 기준농도표, 서식 1~9 |
| 경기도교육청 과학교구·설비 기준 (2025) | 교구 고시 | 교구 코드·종목·소요기준, 안전설비·안전장구 기준 |
| 화학물질의 분류·표시 및 MSDS에 관한 기준 (고용노동부 고시) | 법령 | 경고표지 작성 규칙, MSDS 16개 항목, GHS 유해성 분류 |

검토 범위
- 충북 계획은 과학실 관리와 관련된 부분(안전한 과학실 조성, 부록의 폐수 처리·서식·법규)을 읽었다. 나머지 과학교육 사업 내용은 앱과 관련이 없어 훑기만 했다.
- 고용노동부 고시는 Google Drive 텍스트 변환이 별표 2(경고표지 기재항목) 중간에서 끊겨 있었다. 별표 3(경고표지 양식·규격)은 서울 매뉴얼 서식 4에 같은 내용이 실려 있어 그것으로 확인했다. 별표 4(MSDS 세부 항목)는 원문 PDF 확인이 필요하다.
- 별표 1(유해성 분류 시험 기준) 본문은 분류 항목 목록만 확인했다. 앱은 분류를 직접 하지 않고 MSDS에 적힌 분류를 가져다 쓰므로 세부 시험 기준은 필요 없다.

- 점검자(과학부장), 확인자(교감), 결재자(교장) 서명란이 있다. 출력물에는 서명할 빈칸을 남긴다.
- 학교용 서식은 내용이 모두 포함되면 수정해서 써도 된다 (경기 매뉴얼 명시).
- 장부는 전산 관리가 가능하지만, 과학실마다 게시·비치할 방법을 마련해야 한다.

### 2-2. MSDS 관련 법적 주의사항

앱 설계에 직접 영향을 주는 내용이다.

1. **법적으로 유효한 MSDS는 시약을 판매한 업체가 제공한 것뿐이다.** 인터넷(안전보건공단 등)에서 받은 MSDS는 법적 효력이 없다. 업체를 확인할 수 없을 때만 사유와 근거를 남기고 공단 자료로 대체할 수 있다(이 경우도 법적 보장은 없음).
2. **MSDS를 전산장비(앱)로 게시하는 것은 허용된다.** 단, 아래 4가지를 모두 갖춰야 한다.
   - 취급자가 작업 중 쉽게 접근할 수 있는 장소에 장비가 설치·가동될 것
   - 취급자에게 프로그램 사용법과 MSDS 확인 방법을 교육할 것
   - 관리요령 게시물에 MSDS 검색 방법을 포함할 것
   - 취급자가 실제로 장비로 MSDS를 확인할 수 있는지 사업주가 확인할 것
3. 용기에는 경고표지를 붙여야 한다. 위반하면 과태료 대상이다.

→ 앱에서는 **업체 제공 MSDS 파일을 시약별로 보관·열람하는 기능이 기본**이 되어야 하고, data.go.kr API(안전보건공단 MSDS 정보)는 **경고표지 작성과 정보 확인을 돕는 보조 자료**로 쓰는 것이 안전하다.

### 2-3. 경고표지 작성 규칙 (출력 기능)

고용노동부 고시와 서울 매뉴얼 서식 4 기준.

- 기재 항목: 명칭, 그림문자, 신호어, 유해·위험 문구, 예방조치 문구, 공급자 정보
- 100g 또는 100mL 이하 용기는 명칭, 그림문자, 신호어, 공급자 정보만 표시해도 된다.
- 그림문자 규칙
  - "해골과 X자형 뼈"와 "감탄부호"가 둘 다 해당되면 해골만 표시
  - 부식성과 피부·눈 자극성이 둘 다 해당되면 부식성만 표시
  - 호흡기 과민성과 피부 과민성·자극성이 둘 다 해당되면 호흡기 과민성만 표시
  - 5개 이상이면 4개까지만 표시 가능
- 신호어: "위험"과 "경고"가 둘 다 해당되면 "위험"만 표시
- 예방조치 문구가 7개 이상이면 예방·대응·저장·폐기 각 1개 이상을 포함해 6개까지만 표시하고, 나머지는 MSDS를 참고하라고 적는다.
- 크기: 용량 5L 미만은 용기 표면적의 5% 이상. 그림문자 하나는 표지 면적의 1/40 이상, 최소 0.5㎠.
- 색: 바탕 흰색, 글씨·테두리 검정, 그림문자 테두리 빨강
- 용기가 작아 붙이기 어려우면 꼬리표로 달 수 있다.
- 서울 매뉴얼은 접착식 용지에 인쇄해 부착하고, MSDS QR코드를 병에 붙이는 방법도 권장한다.

그 밖에 출력이 필요한 게시물
- **유해화학물질 표시**: 유해화학물질 보관 장소 입구에 부착. 흰 바탕, 검정 테두리, 빨간 글씨, 관리책임자와 비상전화 기재 (충북은 A4~A3 출력)
- **시약장 목록표**: 시약장에 보관 약품 목록과 주요 그림문자를 붙이는 것이 우수사례로 소개됨

### 2-4. 유해화학물질 판정

- 같은 물질이라도 **농도에 따라** 유해화학물질 여부가 달라진다. 예: 염산은 10% 이상이면 유독물질, 9%면 해당 없음.
- 경기 매뉴얼 부록 9에 학교에서 쓰는 46종의 유독물질·사고대비물질 기준농도와 CAS 번호가 정리되어 있다.
- 유해화학물질을 보유하면 따라오는 의무
  - 주 1회 취급시설 자체점검대장 작성(5년 보존)
  - 별도 보관, 잠금장치, 취급주의 표시
  - 1년에 1번이라도 사용하면 취급 교직원 특수건강진단 대상
  - 사고대비물질은 취급 내용을 기록해 5년 보존

→ 시약을 등록할 때 **CAS 번호와 농도를 받아 유해화학물질 여부를 자동 판정**하고, 해당 시약이 있으면 주간 점검대장을 활성화하는 식으로 연결할 수 있다.

### 2-5. 시약 보관 위치 추천 기준

매뉴얼 3종의 기준을 합치면 아래와 같다.

**보관장 종류와 넣을 시약** (충북 계획의 보관장별 분류 예시 기준)

| 보관장 | 칸(분류) | 예시 |
| --- | --- | --- |
| 밀폐형 약품장 | 산 | 염산, 질산, 황산, 아세트산(빙초산), 인산 |
| | 염기 | 수산화 나트륨, 수산화 칼륨, 수산화 칼슘, 암모니아수 |
| | 위험성이 높은 무기화합물 | 과망가니즈산 칼륨, 질산은, 질산칼륨, 아이오딘, 과산화수소, 브로민 |
| | 금속 | 알칼리금속(석유 속 보관), 마그네슘, 철가루, 아연, 구리 |
| 가연성 물질 전용 보관장 | 인화성·휘발성 | 에탄올, 아세톤, 황가루 |
| 일반 약품 보관장 | 위험성이 낮은 무기·유기화합물 | 탄산칼슘, 염화칼륨, 포도당, 지시약 용액 |

**공통 원칙** (서울·경기 매뉴얼)
- 무기 화합물과 유기 화합물을 분리
- 산과 염기 분리, 무기산 분리
- 인화성 액체는 무기 화합물과 분리된 칸에 보관
- 위험성이 크거나 유해 증기가 나오는 약품은 밀폐형 시약장, 냄새·증기가 없는 약품은 일반 시약장
- 독극물은 별도 보관, 이중 잠금
- 공존할 수 없는 물질끼리 먼저 나눈 뒤, 같은 분류 안에서는 가나다순으로 정리
- 눈높이 아래에 보관, 선반에 밀집 보관하지 않기
- 시약장은 환기가 잘 되고 직사광선이 없으며 사람이 오가지 않는 곳에 설치

**함께 두면 안 되는 물질** (서울 매뉴얼 참고자료 2, 충북 부록)
- 수십 개 물질의 공존 불가 목록이 있다. 예: 질산 ↔ 아세트산·가연성 액체, 과산화수소 ↔ 금속·알코올·아세톤, 알칼리 금속 ↔ 물·이산화탄소·할로젠, 암모니아 ↔ 수은·염소·아이오딘

→ 시약마다 **보관 분류(산, 염기, 산화제, 인화성 등)**를 정하고, 시약장 구역마다 **허용 분류**를 설정하면 다음 기능을 만들 수 있다.
- 새 시약을 등록할 때 넣을 구역 추천
- 같은 구역에 공존 불가 물질이 있으면 경고
- 현재 배치에서 규칙에 어긋난 시약 목록과 재배치 제안 (정돈 기능)

### 2-6. 교구·설비 관리

경기 과학교구·설비 기준에는 다음 정보가 있다.
- 교구: 교구코드(예: 공통1, 물질3), 분야, 종목명, 규격, 소요기준(학교당, 실험실당, 4학생당 1 등), 필수/권장, 소모성 교구 여부
- 학교급별 목록: 초등 85종, 중학교 125종, 고등학교 184종
- 안전설비 18종, 안전장구 15종의 기준 수량
- 소요수량 계산 규칙: 학교당은 그대로, 실험실당은 실험실 수를 곱함, 학생당은 가장 많은 학급의 학생 수를 나누고 올림

사용연한·점검 주기 관련 내용
- 소화기 내용연수 10년, 제조연월과 압력계 확인
- 안전장구는 사용기한과 청결 상태를 정기 점검 (조례)
- 구급약품 유효기간, 밀폐시약장 필터 교체 주기
- 일반 교구의 사용연한은 매뉴얼에 없다. 별도 기준(예: 물품 내용연수 기준) 확인이 필요하다.

→ 교구 기준표를 기본 목록으로 넣어 두면, 학교가 보유 수량만 입력해도 **확보율과 부족 교구**를 보여 줄 수 있다. 연 1회 교구·안전장비 보유현황 점검 제출 자료로도 쓸 수 있다.

## 3. 구현할 기능 정리 (안)

### 3-1. 기본 구조
- 과학실(여러 개 가능) → 보관장(교구장, 시약장 등) → 구역(칸)
- 법정 게시물과 점검표는 과학실마다 따로 관리 (과학실이 2개 이상이면 각각 비치해야 함)

### 3-2. 기능 목록

| 영역 | 기능 | 매뉴얼 근거 |

## 4. 확정된 결정

| 항목 | 결정 |
| --- | --- |
| 장부 양식 기준 지역 | **충북이 기본값.** 설정에서 서울·경기 양식을 선택할 수 있게 한다. |
| 학교급 | **중학교·고등학교** 기준. 교구 기준 목록은 중학교(125종)·고등학교(184종)를 쓴다. 지금 가진 교구 기준은 경기 고시이므로 충북 기준을 따로 받기 전까지 참고 목록으로 쓴다. |
| MSDS 운영 | **업체 제공 MSDS 파일이 원칙.** 시약별로 업체 파일을 보관·열람한다. data.go.kr API 정보는 "참고자료"로 구분해서 보여 준다. |
| 화학약품 관리대장 | 학교에서는 보통 **수기로 작성**한다. 앱은 입고·사용·폐기 기록을 받아 **충북 서식3 「화학물질 관리대장」** 양식으로 출력한다. 에듀파인 연동은 하지 않는다. |
| 교구 사용연한 | 사용연한은 **선택 입력(빈칸 허용)**. 대신 **취득일과 등록일**을 기록한다. |

충북 서식3 「화학물질 관리대장」 항목 (출력 기준)
- 상단: 약품명, CAS No., 금지물질·허가물질·제한물질·유독물질·사고대비물질 해당 여부(○ 표시)
- 기록 칸: 연월일, 수불구분(입고/출고), 수불량, 보유량, 잔량, 용도(실험/구입처), 확인, 비고
- 안내: 구입·보관·폐기량을 기록해 5년 비치. 유해화학물질(유독물질, 사고대비물질)은 약품명을 형광펜 등으로 눈에 띄게 표시 권장
