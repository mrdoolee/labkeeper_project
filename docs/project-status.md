# LabKeeper 작업 현황

마지막 정리: 2026-10-24 · 이 문서는 "지금까지 한 일"과 "앞으로 할 일"을 한곳에 모은 것입니다. 지금까지는 Claude Code 클라우드 세션에서 작업했고, **이후로는 선생님 PC(로컬)에서 작업합니다** — 준비 방법은 아래 "0. 로컬 작업 환경". 결정 사항의 원문은 [CLAUDE.md](../CLAUDE.md), 진행 체크리스트는 [README.md](../README.md)에 있습니다.

## 0. 로컬 작업 환경 (PC로 옮길 때 한 번)

**설치할 것**
- **Git** — https://git-scm.com (Windows는 "Git for Windows". Claude Code가 Windows에서 Git Bash를 씁니다)
- **Node.js 22 LTS 이상** — https://nodejs.org (22.12 이상 또는 24. 설치 후 `node -v`로 확인)
- **Claude Code** — 데스크톱 앱 또는 터미널용(`npm install -g @anthropic-ai/claude-code`)

**저장소 받기**
```bash
git clone https://github.com/mrdoolee/labkeeper_project.git
cd labkeeper_project
```
그다음 이 폴더를 Claude Code로 엽니다. 세션이 시작되면 훅이 알아서 `gas/`, `web/`에 패키지를 설치합니다(처음 한 번 1~2분, 그 뒤로는 바로 끝남). 직접 하려면 `cd gas && npm install`, `cd web && npm install`.

**브라우저 시험(e2e)을 처음 돌리기 전에 한 번**
```bash
cd web
npx playwright install chromium
```
(클라우드 세션에는 Chromium이 미리 있어서 필요 없었습니다. `web/playwright.config.ts`가 PC에서는 Playwright가 설치한 Chromium을 씁니다.)

**자주 쓰는 명령** (자세한 것은 CLAUDE.md "개발 명령")

| 하려는 것 | 명령 |
|---|---|
| 서버(GAS) 시험 | `cd gas && npm test` |
| 화면 시험 · 타입 검사 · 빌드 | `cd web && npm test`, `npx tsc -b`, `npm run build` |
| 브라우저 시나리오 시험 | `cd web && npm run e2e` |
| 내 PC에서 화면 띄워 보기 | 터미널 1: `cd gas && npm run dev` (가짜 시트 서버, http://127.0.0.1:8787) · 터미널 2: `cd gas && npm run dev:admin` (학교 정보와 첫 계정 kim / first-pass-1 만들기) · 터미널 3: `cd web && npm run dev` → http://localhost:5173 열고 연결 화면에 `http://127.0.0.1:8787/` 입력 |
| 학교용 GAS 한 파일 만들기 | `cd gas && npm run bundle` → `gas/dist/LabKeeper.gs` |

**알아 둘 점**
- `main`에 올리면(push) Vercel이 공용 화면을 자동 배포합니다. GitHub 로그인은 처음 push할 때 Git이 물어봅니다(Git Credential Manager).
- 커밋 작성자 이메일: 클라우드에서는 GitHub의 noreply 주소를 썼습니다. PC에서 개인 이메일 공개를 막아 두셨다면 `git config user.email "<GitHub 설정 → Emails의 noreply 주소>"`를 저장소에서 한 번 설정하세요.
- 로컬 가짜 시트 서버는 메모리에만 저장해서, 끄면 데이터가 사라집니다(시험용).

## 4. 미뤄 둔 작은 문제 (나중에 정리)

**화면·사용성**
- 시트의 참·거짓 값이 `TRUE`/`FALSE`, 보관장 종류·보관 분류·역할이 영어 코드(`sealed`, `admin` …)로 보임
- 보관장 탭에 교실 이름 대신 교실 ID (교실 이름이 바뀌면 함께 고쳐야 해서 보류)
- 개발용 시트의 옛 기록 행은 작성일시가 세계 표준시(…Z) 그대로
- 구역 저장 후 "저장했습니다" 표시 없음, 비밀번호 초기화·사용 중지 전 확인창 없음, 자기 역할을 바꾸면 새로고침 전까지 화면에 반영 안 됨
- 보관장 종류를 바꿔도 구역의 허용 보관 분류는 예전 그대로
- 교실 카드는 제목을 눌러야 열림(카드 전체가 아님)
- 메뉴 접기 버튼의 화면 읽기용 정보(aria-expanded) 부족
- "스프레드시트 열기"가 팝업 차단에 걸리면 반응 없음
- 로그인 확인 중 연결이 끊기면 연결 오류 대신 로그인 화면이 나옴

**서버·안정성**
- 이력을 볼 때마다 그 분야 이력 탭 전체를 읽음(몇만 줄이 넘으면 느려질 수 있음 → 해마다 정리 기능)
- 이미 삭제된 기록을 또 삭제·수정할 수 있음
- 알 수 없는 기능 이름 요청이 "서버 오류"로 응답, 로그인 처리 중 잠금 유지·아이디 존재 여부 시간차
- 연결 확인 응답이 정말 LabKeeper인지 검사하지 않음, 첫 연결 때 잠금 없이 시트·설정을 만들 수 있음
- 다른 탭에서 학교를 바꾸면 기존 탭은 이전 로그인 정보를 잠시 더 가짐
- 같은 주소라도 대소문자만 다르면 "다른 학교" 확인이 뜸
- 보관 분류 id 목록 시험이 화면 쪽 목록과 직접 비교하지 않음

**실제 구글 환경에서 한 번 확인할 것**
- "사본 만들기" 때 스크립트 설정값이 복사되는지(사본 감지·원본 표시의 전제)
- 1000줄이 넘을 때 행 추가, 1행 고정된 탭 비우기
- 시트 메뉴 대화상자(첫 계정, 학교 정보)와 이메일 권한 승인

**개발 도구**
- e2e를 돌릴 때마다 스크린샷 파일이 바뀜(시각이 찍혀서)
- 린트 경고 10건(React effect 안 setState 등, 오류는 없음)
